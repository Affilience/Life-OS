## 🎯 Prestige System

### Prestige Tiers
- **Prestige 0** (Mortal Realm) - 1x XP multiplier
- **Prestige 1** (Cosmic Ascension) - 1.5x XP multiplier
- **Prestige 2** (Transcendent) - 2x XP multiplier

### How It Works
1. Reach Level 100
2. Use `avatarStore.performPrestige()`
3. Reset to Level 1 but keep prestige count
4. Earn XP faster with multiplier
5. Progress through stages again with bonuses

## ⚡ Technical Features

### Non-Blocking Generation
- **40 character sprites** queued simultaneously via PixelLab MCP
- **16 equipment items** queued in parallel
- Jobs process in background (2-5 minutes each)
- Download when ready (no waiting during development)

### Equipment Rendering System
- **Direction-based z-ordering** (equipment renders in correct layer based on facing direction)
- **Rarity effects**:
  - Rare: Subtle glow (shadowBlur: 5px)
  - Epic: Medium glow (shadowBlur: 10px) + 2 particles
  - Legendary: Strong glow (shadowBlur: 15px) + 5 particles + pulsing aura
- **Dye system** uses multiply blend mode for palette swapping
- **Transmog system** separates visual appearance from stats

### Performance Optimizations
- **Lazy loading** for all components
- **Pre-compositing** for equipment layers
- **Sprite atlasing** support (future enhancement)
- **Pixel-perfect rendering** with Math.floor() coordinates
